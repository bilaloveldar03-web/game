# Бесплатный поток данных для ФНЛ Менеджера

[Игра](https://fnl-manager-41-play.bilaloveldar03.chatgpt.site) · [История запусков](https://github.com/bilaloveldar03-web/game/actions)

Срез **7 ноября 2026, 03:30 по Екатеринбургу**: 13 дивизионов, 255 клубов, 1510 подтверждённых
завершённых матчей, 6 кратких новостей и 13 обзоров последних результатов. Составы — отдельный

## Обновление

Обычный GitHub Actions Linux runner ежедневно около **05:37 UTC / 10:37 Екатеринбург** читает
восемь бесплатных файлов openfootball/football.json и проверенную массовую выгрузку
`data-sync/inbox/snapshot.json`. Сохраняет более свежий полный компонент в `data/live.json`.
Нет платных API, подписок или ключей. Ручной запуск: Actions → Free football data sync → Run workflow.

В проверенном срезе результаты российских лиг взяты из календарей и таблиц «Чемпионата», десяти
европейских дивизионов — из Football Web Pages. У каждой игры сохранена ссылка на источник.
РПЛ, Первая лига и Вторая лига А доступны наряду с АПЛ, Чемпионшипом, английскими Лигами 1/2,
Ла Лигой, Бундеслигой, Серией А, Лигой 1 Франции, Эредивизи и Португалией.

**Ежедневный запуск не означает ежедневную повторную сверку спортивных сайтов.** Обычный
upstream пока содержит более старые результаты. Проверенный срез не откатывается к ним.
`checkedAt` каждого компонента — дата сверки спортивных источников, `dataAsOf` — дата последнего
завершённого матча, `generatedAt` — время работы job. Для следующей сверки заменяется одна общая
выгрузка, без ввода клубов по одному. Коллектор обращается только к raw.githubusercontent.com;
скрейперы закрытых сайтов и обход ограничений не используются.

## Проверки и поведение игры

Таблицы согласуются с финальными результатами по играм, победам, ничьим, поражениям, голам и очкам.
Снятие четырёх очков с Southampton сохранено. Вторая лига разделена на осенние группы «Золото»
(10 клубов) и «Серебро» (7); все 42 матча «Серебра» завершены. Новостная лента содержит краткие
пересказы и ссылки, а не полные статьи. Live-результаты не считаются завершёнными.

Новая карьера стартует 7 ноября. История счетов уже входит в очки и не пересчитывается повторно.
Сохранённая карьера сохраняет свои результаты, финансы и развитие игроков. Для неё реальная
таблица остаётся отдельным справочником. Будущие неподтверждённые даты в игре моделируются.
Опубликованные реальные даты показываются отдельно.

Рейтинги — **игровая модель командной формы**, не новая индивидуальная оценка EA или Football Manager.
Используются очки за матч, разница голов и последние пять результатов с уменьшением веса малой
выборки. Поправка клубного рейтинга ограничена ±4, OVR игрока — ±2 и его потенциалом. Повторное
применение не суммирует поправку. Технические и физические характеристики, цены и зарплаты
по результатам команды не изменяются. Отсутствующие индивидуальные оценки не выдумываются.

## Стоимости Transfermarkt

Текущая массовая выгрузка цен по-прежнему отсутствует; модельные цены не выданы за реальные.
Поддерживается один разрешённый датированный файл `data-sync/inbox/market.json` для всех игроков.
Нужны `checkedAt` и массив `players` с полями `transfermarktId`, `name`, `dateOfBirth`, `valueEUR`,
`valuationDate`, `sourceUrl`. Имя, дата рождения и установленный ID проверяются. Старые оценки и
неоднозначные сопоставления автоматически не применяются. Не добавляйте секреты в публичный репозиторий.

## Запуск

```sh
python -m unittest discover -s data-sync -p 'test_*.py'
python data-sync/collector.py
```

Job ограничен 12 минутами и не запускает сам себя. Ошибка или старый ответ не заменяют последнюю
корректную базу. Расписание GitHub может задерживаться; после 60 дней без активности публичного
репозитория оно может быть отключено GitHub. Данные openfootball — CC0; источники проверенного
среза перечислены внутри его компонентов.
